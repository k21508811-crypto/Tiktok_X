Возможности прототипа

  • Тёмная тема с красными и голубыми акцентами.
  • Быстрый переход на публичный сайт TikTok.
  • Демонстрационный раздел избранного.
  • Настройки интерфейса.

Важно: TikTok X — независимый неофициальный проект. Он не связан с TikTok или ByteDance, не модифицирует официальное приложение, не предоставляет доступ к закрытым API и не обходит ограничения платформы. Названия и товарные знаки принадлежат их правообладателям.

APK пока доступен только как тестовый артефакт GitHub Actions после успешной сборки. Перед публичным релизом потребуется проверка, постоянная подпись APK и политика конфиденциальности.
